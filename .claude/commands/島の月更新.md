アンリ・リノのクイズアプリ **ANRINO（ena-quiz）** の島とクエストを、月の更新にあわせて育てる。
**応答・画面の文言はすべて日本語（子ども向けは ひらがな多め・分かち書き）。**

## 全体の方針（決定済み。変えるときはユーザーに聞く）
**「島はずっと続く。毎月、新しい仲間と季節と建物がやってくる」**
- その月の教科キャラ＝**主役**。前の月の子＝**住人**（毎日 `visitorsFor` で日替わりに遊びに来る。合計7体めやす）。なかよし度・きせかえは char キーで永久に引きつぐ。
- 景色は実際の月で自動に変わる。季節の品はその月だけ売る（買ったものはずっと使える）。
- 建物は毎月2つずつ、その月の単元にちなんだものを `BUILD_ORDER` の後ろに足す。値段は前の月より上げていく（9月 30〜250、10月 300・400）。
- メダルは クイズとクエストだけが増やす。島は使うだけ（`spend()` を必ず通す）。

## 手順A：新しい教科キャラを足す（その月・その教科に問題を入れたとき）
1. **動物を決める**。これまでの動物とかぶらせない（`grep -n "^function render[A-Za-z]*SVG" index.html` で一覧）。その月の単元にちなんだ小物を Lv3〜5 で持たせる（例：くまのツキミ＝月・ぼうえんきょう・おだんご）。
2. **index.html に3か所**（python の置換で。`assert s.count(a)==1` で場所を確かめる）
   - `render○○SVG(level, fillPct, size, opts)` を `// ホームの育成カード` の見出しの直前に追加。**既存の `renderRabbitSVG` / `renderBearSVG` をひな形にする**（`petEggBody`・`petRingBG`・`petCommonDeco`・`petEyes`・`petWrapSVG` を使う。Lv1＝たまご、Lv6＝かんむり）。
   - `CAT_CHARS` に設定（title・short・render・phases・shard・complete・grew・grewNew・starKick・starSub・dexNote・levels 6段）。
   - `MONTH_CAT_PET['2026MM']` に `{ 教科: 'キャラ名' }`。
3. `python3 tools_extract_202609.py` → `js/chars.js` に `○○: render○○SVG` が入る。`git diff --stat js/util.js` が空であること。
4. **島側** `game-src/src/lib/chars.ts`：`CharKey` に小文字キー、`CHAR_NAMES` に名前を1行ずつ。好物は `lib/items.ts` の `FAVORITE` に（季節の品は好物にしない＝翌月から買えなくなる）。
   - 島のキャラ名は `islandCharKey()` が render○○SVG から自動で決めるので、index.html 側の対応表は不要。

## 手順B：季節と建物（月の変わり目の前にやっておく）
- **季節の景色**：`components/IslandStage.tsx` の `SeasonDeco`（いま 10・11・12・1・2月あり）。飾りは `SEASON_SPOTS`（建物・観覧車・おつきみだいと重ならない芝のふち）に置く。
- **季節の品**：`lib/items.ts` に `season: 月` 付きで追加（gift は `love`、fwear は `once:true`）。fwear は `screens/IslandScreen.tsx` の `WEAR_POS` に頭の位置も足す。
- **建物**：`ITEMS` に `kind:'building'` → `BUILD_ORDER` の後ろに追加 → `components/BuildingSVG.tsx` に絵と `BUILDING_SPOTS`（割合座標）。島の広さは expansion 2 で上限なので、置き場所は既存の建物と重ならないところ（家0.2,0.42／灯台0.87,0.43／学校0.64,0.36／観覧車0.12,0.66／天文台0.44,0.32／お月見0.80,0.80）。
- 🌉となりの島（east）と🏠おうちの中（house）は作成済み（下の「場所（エリア）」）。11月以降の建物は east に建てるのがおすすめ。
- クエストの月は**自動**（2026-09-24〜）：毎月6日に新しい月へ（rpg.html `QUEST_SWITCH_DAY`）。**島の主役（currentMonth）も同じく6日に切りかわる**（index.html `ISLAND_SWITCH_DAY`。変えるときは両方直す。季節の景色・品はカレンダーの月のまま）。`python3 tools_extract_202609.py` を回せば 9月以降の全部の月の `data/questions_<月>.json`・`quest_months.json` ができる。新しい月の問題を足したら必ず回す。確認は localhost の rpg.html に `?today=YYYY-M-6`・`?month=YYYYMM`。
