## 手順

1. **入れ先を決める**
   - 月（`MONTHS`: 202605〜202610・eikoh_*）と教科（`CATEGORIES`: shakai / rika / kokugo / sansu / eigo）。
   - 単元は「グループ（`isGroup: true`）＋子（基本問題・練習問題）」の形。
     例: `nougyou1`（日本の農業１🌾）＋ `nougyou1_kihon` ＋ `nougyou1_renshu`。
   - 新しいグループなら `SUBJECTS` に追加し、CSSに `.tag-xxx { background: …; color: …; }` を1行足す。
   - **既存グループに子タイルを足すだけなら CSS は不要**（親と同じ `tag-xxx` を使い回す）。
   - 過去問は `xxx_kakomon: { label:'過去問演習', icon:'📋', …, parent:'xxx' }`、IDは `xxx_k01`〜 の形で統一している。
   - **タイル名は短く**（4文字が目安。長いと折り返して崩れる）。グループの絵文字は月タイル（🌸☔🌻🍉🌰🍁）と重ねない。6文字くらいまでなら折り返さないことを確認済み（「約数と公約数」）。
   - **SUBJECTS には必ず `month` を付ける。** `ref`（教科書ページ）付きの単元は問題0問でもタイルが出るので、月がないと**全部の月**に「教科書を見る」が出てしまう（5月の小数・単位・分数が9月の算数に出ていた）。

2. **図を用意する**（写真があるとき）
   - `Read` で中身を確認。**紙を撮った写真は必ず照明ムラがある**ので、単純な明暗補正（閾値・autocontrast）はやらない。暗い側が真っ黒につぶれて作り直しになる。
   - **この関数をそのまま使う**（背景で割ってから伸ばす。線だけ黒く残る）:
   ```python
   from PIL import Image, ImageFilter
   import numpy as np
   def clean(im, radius=35, gain=1.12):
       g = im.convert('L')
       bg = g.filter(ImageFilter.GaussianBlur(radius))
       a = np.array(g).astype(np.float32); b = np.array(bg).astype(np.float32)+1e-3
       r = np.clip(a/b*255.0*gain, 0, 255)
       return Image.fromarray(np.clip((r-150)*255.0/(238-150),0,255).astype(np.uint8)).convert('RGB')
   im = clean(Image.open(src).crop(box))      # 紙の余白は crop で落とす
   im = im.resize((1200, round(im.height*1200/im.width)), Image.LANCZOS)
   im.save(dst, quality=85)                   # 幅1200px・quality 85
   ```
   - **表示は `.question-img { max-height: 360px }` で頭打ち。縦長にするほど小さくなる。**
     - 図が2枚必要 → **合成せず `qImage` と `qImage2` の2枚指定**（renderは両方対応済み）
     - 選択肢の図が6個並ぶもの → **2段×3列**に組み直すと1個あたりが大きくなる
     - 縦長グラフ1枚（縦横比0.8くらい）はそのままでもスマホで読める（確認済み）

3. **問題を書く**（`QUESTIONS` 配列に追加。既存の単元の近くに置く）
   ```javascript
   { id:'nog1_01', subject:'nougyou1_kihon', month:'202609', type:'selfjudge',
     qImage:'/images/nougyou1_map.jpg',       // 図がないときは省略
     q:'基本問題1-(1)\n問題文…',
     answer:'こたえ',
     explanation:'解説…' },
   ```
   - 形式は **choice**（`options` 配列＋`answer` は0からの番号）/ **selfjudge**（`answer` は文字列・自分で丸つけ）/ **input** の3つだけ。
   - **算数は input が基本。** 判定は `parseFloat` の数値比較なので `answer:'12個'` なら「12」でも「12個」でも正解。
     - 答えが1つの数 → input。すべて答える・2つ答える・素因数分解 → selfjudge（「、」区切り。CSVの「」は外す）。
     - **分数の答えは `answer:'3/10'`、帯分数は `answer:'1 1/4'`（半角スペース）。** `/` を含むと分子・分母の入力欄、スペース付きだと「整数 と 分子/分母」の欄になる。
     - 仮分数でも正解にしてよい（CSVに「1と1/4 (5/4)」とあれば両方正解）。**約分が条件の問題は `mustReduce:true`** を付ける（2/4 などは不正解＋「約分しきれていない」注意が出る）。
   - 問題文の式は `\n` で改行して次の行に置く（例 `'基本問題1-1-(1)\n次の小数を分数になおしなさい。\n0.3'`）。※問題文の改行は今は画面で無視され、同じ行に続けて表示される。
   - 「すべて選びなさい」は未対応 → 選択肢を問題文に `【ア：…／イ：…】` と書いて selfjudge で記号を書かせる。
   - **IDは既存と絶対に重複させない**（例: `ng1_` は「流れる水」で使用済みだったので農業は `nog1_` にした）。手順5で必ずチェック。
   - 問題文の先頭に `基本問題1-(1)\n` のように番号を入れる。
   - **出題順はシャッフルされる。** 複数問で共通の前置き（「満月から次の満月まで約29日として」など）は、関係する問題すべてに書く。1問目にだけ書くと他が解けなくなる。
   - 選択肢が図の番号を指すだけのときは `options:['1','2','3','4']` と番号だけにする（文章を付けると答えが透ける）。丸数字①〜⑦もそのまま使える。

4. **ユーザーのCSVをそのまま信じない**（毎回ここで直す）
   - **答えのヒントが問題文に混ざっている**ことがある（例「（「棚田」または「千枚田」）」）→ 消す。**消したことを報告する。**
   - 選択肢に地域名など答えが透ける情報 → 記号（ア〜キ）だけにする。**地図と名前が合っているかも確認する**（実際に食いちがっていたことがある）。
   - **解説はこちらで書く**（教材にはない）。混同しやすいものは違いも書く（二期作と二毛作、てんさいとさとうきび など）。
   - 古い統計は教材の答えのまま入れ、解説に最新を添える（例: 茶の生産量1位は2024年に鹿児島県）。
   - 記述問題は、解説に「〜が書けていれば正解」と丸つけの目安を書く。
   - `1/2` と書くと KaTeX が分数にして崩れる → 社会・理科の文章では**「半分」**。区切りは全角「／」。算数の分数はそのまま `3/4`・`1と2/5` で書けばきれいな分数になる。
   - **答えは必ず自分で計算し直す**（約数・最小公倍数・分数計算など全部）。合っていたら「答えは全問検算して合っていた」と報告する。
   - 解説の改行（`\n`）は表示される（`.feedback-explanation` に pre-line 済み）。手順ごとに改行して書く。
   - 解説で `8×33 / (11×9)` のような式は分数にならず読みにくい → `8/1 × 1/11 × 33/1` の形で書く。
   - 算数の解説の型：約数＝かけ算の組で書き出す／公約数＝最大公約数の約数／公倍数＝最小公倍数の倍数（2数の積が最小公倍数でない例に注意書き）／「〇あまる」は割る数があまりより大きい／範囲の個数は「1〜大きい方」−「1〜小さい方の手前」／切り分け＝最大公約数・しきつめ＝最小公倍数。

5. **チェック**（飛ばさない）
   ```bash
   cd ~/Desktop/開発/ena-quiz && python3 - <<'PY'
   import re, subprocess, os, tempfile
   html = open('index.html', encoding='utf-8').read()
   ok = True
   for i, b in enumerate(re.findall(r'<script(?![^>]*\bsrc=)[^>]*>(.*?)</script>', html, re.S)):
       p = os.path.join(tempfile.gettempdir(), f'blk{i}.js'); open(p, 'w').write(b)

   ```
   （`kk1_*` `kk2_*` `um_k*` は前からある既知の重複。新しく足したIDが出たら直す）

   動物は他の月とかぶらせない（いま22体：…ハムスター・うさぎ(ミミ)・くま(ツキミ)・うし(モモ)）。**キャラ追加の細かい手順は `/島の月更新` を見る**（島・クエストへの反映もそちら）。

   input の答え合わせまで見るときは、入力欄をクリックして type → 「答え合わせ ✅」。分数は分子・分母の欄を別々にクリックする。
   **テストで答えると、そのブラウザにメダル・正解記録が残る**（アプリ内ブラウザだけ。ユーザーの端末とは別）と報告に書く。
   スマホでの見え方は `resize_window` の `mobile` で見て、**終わったら `desktop` に戻す**。
   画面の切りかわりに一拍あるので screenshot は1秒待ってから撮る。
