引数: `$ARGUMENTS`（月と条件。例「10月」「10月 各教科20問」。省略時は聞く）

ANRINO（ena-quiz）に入っている**ある月の問題から、紙で解く模試**を作る。問題用と解答用を**別ファイル**にして、PDFにする。**応答も紙面もすべて日本語。**
前例は9月模試（`print/build_moshi_202609.py`）。**新しい月は、このスクリプトをコピーして直す。**

## 場所

| もの | パス |
|---|---|
| プロジェクト | `~/Desktop/開発/ena-quiz`（`print/` に置く） |
| 元データ | `data/questions_<月>.json`・`data/subjects_<月>.json`（9月以降のみ） |
| 前例（コピー元） | `print/build_moshi_202609.py`・`print/build_pdf_moshi.sh` |
| 出力 | `print/moshi_<月>.html`・`print/moshi_<月>_kaitou.html`・`~/Desktop/ena_<月>模試_問題.pdf`／`_解答.pdf` |

## 手順

1. **データを最新にする**
   - `data/questions_<月>.json` は `python3 tools_extract_202609.py` で index.html から作り直せる（9月以降の月だけ入る。**8月以前は data/ に無い**ので、その場合は index.html の QUESTIONS を node で評価して同じ形のJSONを作る）。
   - 件数を index.html と突き合わせる（古いJSONのまま作らない）。

2. **教科と量を決める**（ユーザーに聞くのは次の3つだけ。デフォルトを添える）
   - 教科：その月に問題がある教科。**問題が0件の教科（9月の英語）は外し、表紙に「〇〇はこの月は対象外」と注記する。**
   - 量：デフォルト **各教科20問**。（1問5点で100点満点にそろえるため。9月は社会19問・国語16問で95点・80点になってしまった。）
   - 画像つき問題を入れるか（デフォルト：入れる）。

3. **選定テーブルを決め打ちで書く**（`SELECTION`）
   - 形は `(subject_id, 採用数, うち画像つき数)`。教科ごとに、単元グループ（例 tsuki1／tsuki2）と 基本・練習・過去問 をまんべんなく。
   - `select()` は「画像つきを先にK_img問＋残りは先頭から」。**画像が後ろの問題に固まっている単元（農業の基本問題）は、先頭N問だと画像が0件になる**ので K_img を必ず指定する。
   - ランダムは使わない（何回動かしても同じ結果に）。

4. **整形**（スクリプト内でやっている。新しい月でも同じ）
   - `q` の先頭行（`基本問題1-(1)\n` の単元内番号）は捨てる。教科ごとに連番を振り直す。
   - 画像の `/images/x.jpg` は `../images/x.jpg` に直す（`file://` で開くため）。
   - 選択肢は元の文字列をそのまま出す（「ア：」「①」がすでに入っている）。

5. **生成して検算**
   ```bash
   cd ~/Desktop/開発/ena-quiz/print && python3 build_moshi_<月>.py
   ```
   合計問題数・type内訳・画像の欠け（なし）を確認。

6. **見た目の確認**
   - **ブラウザペインは `file://` を開けない。** `python3 -m http.server 8917`（ena-quizのルートで）を立てて `http://localhost:8917/print/moshi_<月>.html` を開く。終わったら `pkill -f "http.server 8917"`。
   - ペインが非表示だと screenshot・scroll がタイムアウト／真っ白になる。`javascript_tool` で確認する（画像が壊れていない `naturalWidth>0`・番号プレフィックスが残っていない・解答の件数と番号が問題と一致）。

7. **PDF化**
   ```bash
   bash ~/Desktop/開発/ena-quiz/print/build_pdf_moshi.sh   # 月に合わせて出力名を直したもの
   ```
   ページ数を確認して報告する。**9月は75問・画像12問で問題17ページ・解答3ページ。** 画像・選択肢・罫線の余白で、見積もりより長くなる。

8. **`SendUserFile` でPDF2つを渡す。**

## 目安時間と配点（聞かれたらこれで答える）

- 時間の目安：選択式 40秒〜1分／記述・一問一答 1〜1.5分／算数の計算・数値記入 1.5〜2分（見直し込み）。9月なら理科15〜18分・社会18〜20分・国語18〜22分・算数25〜30分、合計80〜90分。長いので**理科＋社会／国語＋算数の2コマに分ける**のを勧める（大問ごとにページが切れているのでそのまま分けられる）。
- 配点：**1問5点の均等**。各教科20問なら100点。問題数がそろわないときは、追加問題でそろえる（配点をいじって合わせるのは計算がややこしいので勧めない）。

## 報告のしかた
- 何問どの教科から選んだか（単元ごとの内訳・画像つきの数）、**教科を外したならその理由**。
- 確認できたこと（画像が壊れていない・解答が問題と一致・ページ数）と、**確認していないこと（実際に紙に印刷したときの余白・改ページ）**を分けて書く。
- 見積もりよりページ数が増えたときは、減らす方法（採用数を絞る）も添える。
