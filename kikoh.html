🌦 日本の気候 まとめ 🌦

社会・地理 ― 気候区・季節風・雨温図・海流

🌍 気候帯の基本
地球の5つの気候帯
熱帯 🔥・乾燥帯 🏜・温帯 🌿・冷帯（亜寒帯） ❄️・寒帯 🧊
気候は 「気温」 と 「降水量」 の組み合わせで決まる！
熱帯 🔥 乾燥帯 🏜 温帯 🌿 ← 日本の多く 冷帯 ❄️ ← 北海道 寒帯 🧊
🗾 日本の気候帯
日本の大部分 → 温帯
北海道だけ → 冷帯（亜寒帯）
温帯は四季があり、夏は暑く冬は寒い。冷帯は冬がとても厳しく夏は短い。
🗺 日本の6つの気候区
🧊
北海道の気候
📍 北海道
冷帯。梅雨がない。夏は涼しく、冬の寒さが厳しい。
ポイント：梅雨なし！
❄️
日本海側の気候
📍 新潟・富山・金沢
冬に雪がとても多い。北西の季節風が日本海の水蒸気を運ぶ。
ポイント：冬に大雪！
☀️
太平洋側の気候
📍 東京・大阪・広島
夏に雨が多く冬は乾燥。典型的な日本の気候。
ポイント：夏に大雨！
🏔
内陸（中央高地）の気候
📍 長野・山梨
夏冬の気温差が大きい（寒暖差が激しい）。雨が少ない。
ポイント：寒暖差大！
⛵
瀬戸内の気候
📍 広島・香川・岡山
1年中温暖で雨が少ない。山に囲まれていて季節風がさえぎられる。
ポイント：年中雨少ない！
🌴
南西諸島（亜熱帯）の気候
📍 沖縄・奄美
1年中気温が高く梅雨が長い。台風が多い。
ポイント：高温・台風多！

💨 季節風（モンスーン）
☀️ 夏の季節風
太平洋から → 南東から吹く → 太平洋側に大雨 ☔
暖かく湿った空気が南東から入り、太平洋側にたっぷりの雨をもたらす。
❄️ 冬の季節風
シベリアから → 北西から吹く → 日本海を渡る → 日本海側に大雪 ❄️
冷たい風が日本海上で水蒸気を吸い込み、山脈にぶつかって雪を降らせる。太平洋側は山が雪を受け止めるので冬は乾燥する。
💡 絶対覚える！季節風の向き
夏 → 南東から（太平洋から）
冬 → 北西から（シベリアから）
「夏は南東、冬は北西」と声に出して覚えよう！
🌧 梅雨（つゆ）
🌂 梅雨の基本
時期：6月〜7月にかけて雨が多い時期
梅雨前線：停滞前線。暖気と寒気がぶつかって動かない前線
北海道：梅雨がない！（梅雨前線が北海道まで届かないため）
からつゆ（空梅雨）：梅雨の時期なのに雨が少ないこと
❓ なぜ北海道には梅雨がない？
梅雨前線が北海道まで北上しないから！
前線は本州付近で停滞して終わる。
テストでよく出る！「北海道には梅雨がない」とセットで理由も覚えよう。
🌀 台風
🌀 台風の基本
発生場所：熱帯の海上（フィリピン近海・南シナ海）
回転方向：反時計回り（北半球のきまり）
多い時期：夏〜秋（8〜9月）がピーク
上陸すると：地面との摩擦・水蒸気補給が減って弱まる
南西諸島：沖縄・奄美は台風が特に多い
⚡ 特殊な気象現象
🌡 フェーン現象
日本海側から風 → 山を越える → 太平洋側で気温上昇 🔥
山の風下側で、乾燥した温かい風が吹く現象。山を下るときに空気が圧縮されて温度が上がる。日本海側から太平洋側へ、または逆も起きる。
🌬 やませ
北東からの冷たい風 → 東北の太平洋側へ → 冷害 🌾💔
夏に吹く冷たく湿った北東の風。気温が上がらず農作物が育たない「冷害」の原因になる。
🌤 気団（きだん）
小笠原気団（太平洋高気圧）：夏の暑さをもたらす。南東から暖かく湿った空気を送る。
シベリア気団（シベリア高気圧）：冬の寒さをもたらす。北西から冷たく乾いた空気を送る。
📊 雨温図（クライモグラフ）の読み方
📈 グラフの見方
折れ線グラフ → 気温（℃）
棒グラフ → 降水量（mm）
グラフの「形」を見て、どの気候区か当てられるようにしよう！
🧊 北海道
気温が全体的に低い。6〜7月に降水量が急増しない（梅雨なし）。
☀️ 太平洋側
夏（6〜9月）に降水量が多い。冬は乾燥して降水量が少ない。
❄️ 日本海側
冬（12〜2月）に降水量が多い（雪）。夏は晴れて少ない。
⛵ 瀬戸内
年間を通じて降水量が少ない。気温は温暖。グラフが全体的に低い棒。
🔑 雨温図で気候区を判定するコツ
① 気温が全体に低い → 北海道
② 夏に降水量のピーク → 太平洋側
③ 冬に降水量のピーク → 日本海側
④ 1年中降水量が少ない → 瀬戸内
⑤ 気温が高くて降水量も多い → 南西諸島
⑥ 梅雨の時期（6〜7月）に増えない → 北海道
🌊 海流
🔴 暖流（温める）
黒潮（日本海流）
太平洋側を北上
対馬海流
日本海側を北上
🔵 寒流（冷やす）
親潮（千島海流）
太平洋側を南下
（東北・北海道沖）
リマン海流
日本海側を南下
🐟 潮目（しおめ）とは？
黒潮（暖流）と親潮（寒流）がぶつかる場所を「潮目」という。
プランクトンが豊富でよい漁場になる。→ 三陸沖が有名！
⚠️ 間違えやすいポイント
❌ よくある間違い・ひっかけ注意！
❶ 北海道に梅雨がない理由 → 梅雨前線が北海道まで「届かない」から（前線がなくなるわけではない）
❷ 日本海側が冬に雪が多い → 北西の季節風が日本海上を通るときに水蒸気を含むから
❸ フェーン現象で気温が上がるのは → 山の「風下」側（風上側ではない！）
❹ やませは → 東北の太平洋側に吹く冷たい風（夏の風だが気温が上がらない）
❺ 台風の回転 → 反時計回り（北半球）。南半球では時計回り
❻ 瀬戸内が雨少ない理由 → 山に囲まれて季節風がさえぎられるから（海に面しているのに少ない！）
